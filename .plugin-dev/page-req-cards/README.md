# 需求卡片（page-req-cards）

在页面里用 `/`（斜杠菜单）插入「需求卡片」块，把一条需求/待办记成结构化卡片，而不是散落的 Markdown 标题。

字段：
- 类型：UI 调整 / Bug / 功能 / 插件构想 / 其他（决定左边色条与徽章颜色）
- 状态：待确认 → 待处理 → 进行中 → 已完成 / 已关闭（底部按钮切换）
- 优先级：P0 / P1 / P2 / P3（顶栏右侧切换）
- 标题 + 详情描述（可多行）
- owner（负责人）、links（关联编号）可选

无头插件，不占运行窗口；只增强页面编辑器（pageEditor.registerBlock kind=req）。
持久化为 Markdown 的 `:::pageBlock {kind=req}` 指令块，随页面保存/迁移。
