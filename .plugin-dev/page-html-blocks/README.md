# HTML（page-html-blocks）

在页面里用 `/` 插入 **排版** 或 **小网页**，把卡片、刊头、小应用直接放进文档。

## 设计要点：无外框，编辑/预览悬浮

- 内容贴在文档里，插件**不套外框 / 标题栏 / 底色**。默认高度跟内容走。
- 右下角可拖动宽高，写进围栏（如 `width=480 height=320` 或 `width=100% height=100vh`）。定了尺寸后溢出滚动。右上角「自适应」清掉宽高。
- 鼠标**悬停**在该块上时，右上角才**浮出**「预览 / 编辑 / 放大」小工具条（小网页另带高度 H）。
- 点「编辑」→ 变成源码编辑框；点「预览」→ 还原为内容本身。
- **演示开关**：`deck` 写在围栏头上，例如 `:::pageBlock {kind=html plugin=page-html-blocks deck=true}`。默认 true。工具条「演示」点一下即可移出/加入放映。围栏里面直接写 HTML，不要再包一层 JSON。
- **放大**：浏览器真实全屏放映。片子本身不满屏时水平垂直居中；← → ↑ ↓ / 空格翻页，Esc 退出。底栏悬停才出现。

## 两种块

### 1. `/html` — 排版

- 一段 HTML/CSS（可带图片）画在文档里。
- 简单、样式跟文档在一起；脚本不执行。
- 适合卡片、表格、刊头。

### 2. `/htmlframe`（别名 `/slide`）— 小网页

- 一段完整 HTML，作为独立小页面嵌进文档，可以跑脚本。
- 样式与主文档隔离；无边框，内容自带背景更佳。
- 悬停工具条可调高度 H。
- 适合交互小应用 / 示例 / 幻灯片。

## 怎么用

1. 编辑某个页面，输入 `/`，选「排版」或「小网页」。
2. 默认即预览效果；把鼠标移到块上浮出「编辑」，粘贴/修改 HTML。
3. 切「预览」看渲染；只读态直接展示。
4. 数据存成 `:::pageBlock {kind=html}` 或 `{kind=htmlframe}`，随页面持久化。
