# HTML 渲染块（page-html-blocks）

在页面里用 `/` 插入 HTML 块，把「富排版 / 小应用 / 幻灯片」直接渲染进文档。

## 设计要点：无外框，编辑/预览悬浮

- HTML 内容**直接渲染**，插件**不套任何外框 / 标题栏 / 底色**，像文档原生的一部分。
- 鼠标**悬停**在该块上时，右上角才**浮出**「预览 / 编辑」小工具条（iframe 块另带高度 H）。
- 点「编辑」→ 变成源码编辑框；点「预览」→ 还原为内容本身。
- 只读态（非编辑）不显示任何工具条，纯展示。

## 两种渲染方式

### 1. `/html` — HTML 直接渲染（无 iframe）

- 内容：一段静态 HTML（标签 + CSS + 图片），直接渲染进文档。
- 特点：简单、原生、样式还原；但脚本不执行。
- 适用：静态富排版、卡片、表格、概览。

### 2. `/htmlframe`（别名 `/slide`）— HTML iframe 沙箱

- 内容：一段完整 HTML，放进 iframe（sandbox=allow-scripts）隔离渲染，等于文档里嵌一个小网页。
- 特点：可以跑脚本（点击、时钟、轮播、幻灯片翻页都行）；样式与主文档隔离；无边框，内容自带背景更佳。
- 悬停工具条可调高度 H。
- 适用：交互小应用 / 示例 / 幻灯片。

## 怎么用

1. 编辑某个页面，输入 `/`，选「HTML 直接渲染」或「HTML iframe 沙箱」。
2. 默认即预览效果；把鼠标移到块上浮出「编辑」，粘贴/修改 HTML。
3. 切「预览」看渲染；只读态直接展示。
4. 数据存成 `:::pageBlock {kind=html}` 或 `{kind=htmlframe}`，随页面持久化。
