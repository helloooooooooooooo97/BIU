# 标签块

在正文里插入一份标签数据。一次只选一个标签当字段模板（例如「任务」上的优先级、截止日期）；填的值只存在这个块里，不会写进页面上方属性里的标签。同一页可以重复插入同一个标签。

左上角是该标签的视图名，**默认表格**：按属性名 / 属性值手动填写。

实现在 `core-file-system-ui`（内置登记），不需要单独启用本插件。本条目只保留围栏约定与商店元数据。

围栏头：`kind=tag plugin=page-tag`。

## 示例写法

:::editorBlock {kind=tag plugin=page-tag}
{
  "tagId": "",
  "values": {}
}
:::
